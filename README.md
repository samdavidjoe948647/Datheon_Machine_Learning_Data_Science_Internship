# Datheon Machine Learning and Data Science Internship

## Project 1: Iris Multi-Class Classification

### Overview
This project implements a supervised machine learning pipeline to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

### Dataset
The Iris dataset contains 150 samples, four numerical features, and three target classes.

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

### Methodology
1. Exploratory Data Analysis (EDA)
2. Missing-value and class-distribution checks
3. 80/20 training and testing split
4. Feature scaling using StandardScaler
5. Logistic Regression and Decision Tree training
6. Evaluation using accuracy, precision, recall, and F1-score
7. Confusion matrix heatmaps
8. Decision-boundary visualization

### Project File
- `Task1_Iris_Classification.ipynb` — notebook containing the implementation, metrics, and visualizations.

### Results
The notebook includes a comparison of both classification models. Refer to its evaluation table for the actual test results.
